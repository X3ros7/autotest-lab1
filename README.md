# Відповіді на контрольні запитання

## 1. Наведіть види тестування

- За рівнем: модульне, інтеграційне, системне, приймальне.
- За знанням коду: чорна, біла та сіра скринька.
- За метою: функціональне, нефункціональне (продуктивність, безпека, зручність, сумісність), регресійне, димове, санітарне.
- За способом виконання: ручне та автоматизоване.
- За сценаріями: позитивне та негативне.
- За етапом: альфа- та бета-тестування.

## 2. Особливості модульного та приймального тестування

**Модульне:**

- перевіряє окрему функцію, метод або клас ізольовано, залежності замінюють заглушками;
- виконує розробник, метод білої скриньки;
- тести швидкі й автоматизовані, запускаються при кожній зміні;
- швидко локалізує помилку, але не показує, чи відповідає система очікуванням користувача.

**Приймальне:**

- перевіряє систему в цілому на відповідність бізнес-вимогам;
- виконує замовник або користувач, метод чорної скриньки;
- виконується наприкінці розробки в середовищі, схожому на робоче;
- результат: прийняти продукт чи повернути на доопрацювання.

## 3. Призначення бібліотек Mocha та Chai

- **Mocha** це тестовий фреймворк: організовує тести (`describe`, `it`), запускає їх, виводить результати, має хуки (`before`, `beforeEach`, `after`, `afterEach`) та підтримує асинхронні тести.
- **Chai** це бібліотека тверджень: порівнює фактичний результат з очікуваним (`expect(x).to.equal(y)`), має стилі `expect`, `should`, `assert`.
- Разом: Mocha запускає тести та звітує, Chai перевіряє умови всередині них.
